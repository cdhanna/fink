# Fink sample

A small Fade.MonoGame game that plays animations drawn in Fink, to show how an exported atlas gets into a game.

```
dotnet run          (from this folder; needs ../../../fade.mono, the engine, beside the fink repo)
```

- **Left / right** walk the slime.
- **Space** makes it hop. That clip plays once, then the game puts it back to idling.
- **P** swaps its palette. **S** changes its speed.
- Above the player, coins spin, each started at a different frame.
- The parade of slimes plays the slime's whole timeline, once per palette row.
- **M** shows the "light" data map as it is: emissive in red (the slime's eyes), the normal in green and blue.
- The slime stands on its **pivot** (its feet, set in Fink).
- A little coin rides on `POINT_SLIME_TOP`, a point placed on each of the slime's drawings, so it bobs with the hop.

## What's where

| | |
|---|---|
| `art/sample.fink` | The art, as a Fink project. Open it in Fink. |
| `art/make-art.fink-test` | The Fink script that drew it: `Fink.exe --script samples/FinkSample/art/make-art.fink-test`, run from the fink repo root. |
| `Assets/Textures/sprites.png` | The atlas: palette indices in the red channel, every different picture once, trimmed and packed. |
| `Assets/Textures/sprites.palette.png` | 256 colors per row, one row per palette variant (base, red). |
| `Assets/Textures/sprites_palette.fx` | The shader that turns indices into colors. The game's content build compiles it. |
| `Assets/Textures/sprites.light.png` | A data map: emissive in R, the normal's x and y in G and B. |
| `Assets/Textures/sprites.atlas.json` | Pictures, assets and clips with their frame times. `Fade.MonoGame.Fink` reads it. |
| `fink_sprites.fbasic` | `TAG_` and `PAL_` constants and `fink_load_sprites()`. Generated by Fink; listed first in the csproj. |
| `game.fbasic` | The game. |

All of the Assets files and `fink_sprites.fbasic` are written by Fink: **Ctrl+E** (Export Atlases). The folders are set in Fink's Atlas panel, under Settings.

## Changing the art

1. Open `art/sample.fink` in Fink.
2. Change a drawing, or a hold, or a tag.
3. Press Ctrl+E.

While the game runs (Debug), the new pictures and timings show up on their own. If you add, rename or remove a **tag** or **palette variant**, the constants change, so restart the program with F1. The game prints a warning if it's running against constants that are older than the atlas.

## The commands (Fade.MonoGame.Fink)

```
atlas = fink_load_sprites()                  ` generated: loads the atlas
play fink sprite spr, TAG_SLIME_IDLE         ` play a clip from its start
loop fink sprite spr, TAG_SLIME_IDLE         ` the same, but does nothing if already playing it
stop fink sprite spr / resume fink sprite spr / release fink sprite spr
set fink sprite palette spr, PAL_RED
set fink sprite speed spr, 2.0
set fink sprite anchor spr, 0.5, 1.0         ` pin a point of the canvas instead of Fink's pivot (-1: back to the pivot)
fink sprite point x(spr, POINT_SLIME_TOP)    ` where a named point is on screen (and point y)
fink atlas map(atlas, MAP_LIGHT)             ` a data map's texture id, for set effect param texture
fink atlas palette(atlas)                    ` the palette texture's id
set fink sprite frame spr, 3
fink sprite clip(spr)   fink sprite playing(spr)   fink sprite done(spr)   fink sprite frame(spr)
fink clip frames(TAG_COIN_SPIN)   fink clip ms(TAG_COIN_SPIN)   fink palette rows(atlas)
```

The library takes over a sprite's texture, effect, frame, origin and `texcoord1.x` (the palette row). Its position, scale, rotation, color, order and visibility stay yours.
